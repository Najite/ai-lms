> **The Era of "Vibe Coding" is Over. Welcome to Industrial AI Systems Engineering.**

AI:NATIVE OS is an open-source, project-based engineering LMS engineered on a **$0 cloud budget** to transform learners into world-class **AI-Native Software Engineers**.

---

## 🎯 The Core Mission: What is an AI-Native Software Engineer?

Most tutorials treat generative AI as a magic autocomplete widget (tweaking prompts in ChatGPT or copy-pasting Copilot suggestions). In production, this approach leads to cascading hallucination loops, unbudgeted GPU inference bills, memory leaks, and severe security vulnerabilities.

An **AI-Native Software Engineer** does not just consume models — they architect deterministic software around probabilistic intelligence:
1. **Classical Systems Foundations**: Deeply understands raw byte buffers, Unix process sandboxes, asynchronous event loops, relational algebra, and graph traversal.
2. **AI Systems Convergence**: Masters subword BPE tokenization, high-dimensional vector spaces, Reciprocal Rank Fusion (RRF), Graph-RAG, and KV-cache memory paging.
3. **Evals as First-Class Code**: Replaces "eyeball testing" with rigorous, automated CI/CD evaluation matrices (LLM-as-a-Judge, G-Eval) and adversarial red-teaming.
4. **Autonomous Self-Healing Systems**: Designs crash-resilient multi-agent state machines with Write-Ahead Logs (WAL), idempotency guarantees, and real-time AST analysis.

## ⚡ Key Architectural Innovations

### 1. Autonomous Staff AI Agent (`src/lib/agent/staffAgent.ts`)
* **Socratic Ghost**: Background AST watcher that leaves non-spoilering architectural reflections on exact lines in the Monaco IDE.
* **Socratic Griller**: Oral defense interrogator scoring trade-offs upon test passage before awarding XP.
* **Chaos Monkey (P0 Outage Simulator)**: Live 20-minute production crisis room simulating memory leaks, token spikes, and broken clusters with live terminal logs and SLA countdowns.
* **Red-Team Adversarial Arena**: Interactive prompt injection sandbox awarding Hacker XP for discovering bypass exploits.

### 2. $0 Cloud Economic Architecture
* **In-Browser Compute via Pyodide WebAssembly**: Python 3.12 executes directly on the learner's CPU, costing $0.00 in server inference or backend compute.
* **Live Supabase PostgreSQL**: Real PostgreSQL database with `pgvector` enabled and granular Row-Level Security (RLS) policies.
* **Dual-Mode Learning**: Toggle between textbook-grade technical handbooks and Google NotebookLM audio deep-dives.
* **Context Flamegraph & Latency Profiler**: Visual horizontal breakdown of the context window (System, Few-Shot, RAG Chunks, History) with TTFT latency and dollar tickers.

### 3. Better Stack × Evervault Design System
High-density obsidian dark mode (`#07080b`), crisp 1px borders (`#1e222e`), live telemetry pulses (`#10b981`), and dual typography (Geist Sans + Geist Mono).

## 🚀 Quick Start

### 1. Clone & Install
```bash
git clone https://github.com/Najite/ai-lms.git
cd ai-lms
npm install
```

### 2. Environment Configuration
Create a `.env.local` file:
```env
NEXT_PUBLIC_SUPABASE_URL=https://lfsyndffrfwvdfzjsagl.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
