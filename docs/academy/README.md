# Academy & Educational Philosophy

## 1. Purpose

The `/docs/academy` documentation domain defines the pedagogical framework, educational philosophy, and operating principles of the AI-Native Software Engineering Academy.

The academy's mission is to transition learners from traditional coding instruction to **AI-augmented engineering mastery**. Progression is not governed by time-in-seat or vanity metric accumulation (e.g. passive video watching), but by rigorous, evidence-based **Competency Validation** and mastery verification.

## 4. Key Principles

1. **Competency Over Completion**: Finishing a lesson does not equate to mastery. Competency is proven when learners can build, evaluate, and defend software using AI tools.
2. **Evidence-Driven Mastery**: Every advancement in the system requires traceable artifacts (git commits, architecture diagrams, passing test suites, live deployments).
3. **AI-Native Engineering**: Students are taught to design, prompt, audit, debug, and govern AI-generated solutions rather than memorize low-level boilerplate.
4. **Permanent Gate Verification**: Competency Gates are irreversible checkpoints certifying capability at each engineering tier.
